# 2026-08-11 — Proyecto personal de journal con Claude Code

## Qué hice hoy

- Empecé mi proyecto personal para capturar aprendizajes, ideas y tareas usando Claude Code.
- Construí una V1: un journal diario con notas y vídeos.
- Construí una V2: bandejas separadas de Ideas y Tareas, manteniendo siempre la captura rápida separada de la revisión posterior.
- Subí el proyecto a GitHub.
- Cerré la sesión dejando un `HANDOFF.md` para poder retomarlo mañana sin perder contexto.

## Ideas clave de hoy

- Aprendí a usar **Plan Mode** para diseñar antes de construir.
- No todo workflow necesita convertirse en una **Skill** — un CLAUDE.md ya puede definir el comportamiento del proyecto mientras el patrón todavía no esté claro.
- Separar siempre **captura rápida** de **revisión posterior** ayuda a mantener el flujo de trabajo simple, tanto en el journal (V1) como en las bandejas de Ideas y Tareas (V2).
- Aprendí la diferencia entre **memoria** y **CLAUDE.md**: la memoria vive fuera del proyecto (no se sube a GitHub) y guarda cómo prefiero trabajar con Claude Code de sesión en sesión; no es una regla fija del proyecto en sí, sino un ajuste de "cómo colaboramos", distinto de lo que documenta el CLAUDE.md.
