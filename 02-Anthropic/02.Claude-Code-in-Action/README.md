# Claude Code in Action

> Aprende a utilizar Claude Code como un asistente de ingeniería capaz de trabajar de forma autónoma, segura y fiable durante sesiones largas de desarrollo.

---

# Objetivo del curso

Este curso enseña a pasar de utilizar Claude Code como un asistente para tareas puntuales a convertirlo en un agente capaz de trabajar durante largos periodos de tiempo con la mínima supervisión posible.

El foco no está en aprender comandos, sino en diseñar flujos de trabajo seguros, automatizados y verificables.

---

# Temas principales

- Sesiones de trabajo prolongadas
- Modo Plan
- Gestión del contexto
- CLAUDE.md
- Skills
- Hooks
- Modos de permisos
- Rutinas
- Modo Headless
- GitHub Actions
- Revisión de código
- Verificación de ejecuciones
- Plugins

---

# Ideas principales

- Planificar antes de ejecutar.
- Mantener un CLAUDE.md simple y conciso.
- Diferenciar entre convenciones, procedimientos y garantías.
- Automatizar el trabajo repetitivo.
- Verificar las ejecuciones autónomas.
- Compartir configuraciones reutilizables mediante plugins.
